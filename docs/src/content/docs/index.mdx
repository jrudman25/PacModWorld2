## What is PacModWorld2?

PacModWorld2 is a Minecraft mod that adds mobs, items, and movement abilities
from Pac-Man World 2. All Pac-Man World 2 IP belongs to the original copyright
owners; assets for this mod were created from scratch.

:::note
The mod is in development (0.1.0, not yet released) and currently targets
Minecraft 1.21.1 on NeoForge.
:::

## Current features

<CardGrid stagger>
	<Card title="B-Doing" icon="rocket">
		A 3x3 bounce pad that launches players and mobs about 6 blocks into the
		air. Landing on it never causes fall damage. [Read more](/PacModWorld2/features/b-doing/)
	</Card>
	<Card title="Red Rat" icon="warning">
		A small hostile mob that hops around grassy biomes and attacks with a
		short-range flame breath. [Read more](/PacModWorld2/features/red-rat/)
	</Card>
